## 先看你要解决哪一层问题

下载软件、购买服务和编写规则是三件不同的事。看教程时先确认它讨论的是客户端界面、代理内核，还是订阅提供方，这能减少“照做却找不到按钮”的情况。

| 名称 | 负责什么 | 不应据此推断什么 |
| --- | --- | --- |
| 图形客户端 | 管理配置、展示状态、提供操作入口 | 安装完成不代表已有可用节点 |
| 代理内核 | 读取配置并处理连接与规则 | 相同内核不意味着客户端界面一致 |
| 订阅 | 提供配置或节点数据 | 更新成功不保证每个节点都可用 |
| 规则 | 决定流量如何选择策略 | 规则不会自动修复基础网络故障 |
| 控制面板 | 查看与管理正在运行的内核 | 网页面板本身不等于安装好了内核 |

## 名称相近时如何确认身份

1. 打开客户端的关于页面，记录完整名称与版本。
2. 从本站下载页进入对应开发者仓库，比较项目名称。
3. 阅读 README 中的系统支持和发行渠道。
4. 核对教程对应的客户端，不把其他项目的菜单名直接套用。

Clash Verge Rev、FlClash 与 Clash Party 是不同项目；MetaCubeXD 是控制面板。它们之间可以有生态关联，但不能因为名称中出现 Clash 就认为安装方法相同。

## 一个常见误区：更新客户端等于更新配置

客户端升级通常改变软件程序；订阅更新改变配置数据。两者可能分别成功或失败。如果升级后连接异常，记录软件版本并检查配置是否仍被选中，不要立即删除全部本地数据。
